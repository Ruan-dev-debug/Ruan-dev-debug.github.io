# Portfólio Ruan Dener

Site de uma página com animações que respondem ao scroll. Não precisa instalar nada além do navegador.

## Como abrir no VS Code

1. Abra o VS Code e vá em **Arquivo > Abrir Pasta** e escolha a pasta `portfolio-ruan-dener`.
2. Instale a extensão **Live Server** (autor: Ritwick Dey) na aba de extensões.
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.
4. Role a página para ver as animações. Também funciona dando dois cliques em `index.html`.

## O que editar

- **Nome e WhatsApp:** no começo de `script.js`, na linha `var CONFIG`. O número vai com 55 + DDD + número, só dígitos.
- **Textos de cada cena:** em `index.html`, dentro de cada `<section class="scene">`, nas tags `<h2>` (título) e `<p>` (texto).
- **Cores:** no topo de `style.css`, em `:root`.

## Como colocar no ar de graça (para mandar o link aos clientes)

- **Netlify Drop:** entre em app.netlify.com/drop e arraste a pasta inteira para a página. Ele gera um link na hora.
- **GitHub Pages:** suba a pasta em um repositório e ative o Pages nas configurações.

As fontes são carregadas do Google Fonts, então a primeira abertura precisa de internet.
